跟着鱼香ros学ros第一弹！

1.1 Linux终端基础操作

pwd 查看当前终端默认主目录
mkdir 创建文件夹
touch 创建文件
nano 编辑文件
ctrl 对应的命令使用下方的功能
cat 查看文件内容
rm –help 查看命令使用方法
rm/rm -rf …. 删除文件/递归强制删除根目录下所有文件
mv 移动文件 如： mv demo_python_pkg/ chapt2_ws/src/

1.2 Linux环境变量

echo /echo $….. 输出
printenv / printenv ｜ grep …. 打印环境变量的信息/过滤
ros2 run 功能包名 可执行文件名 执行文件
AMENT_PREFIX_PATH=/opt/ros/jazzy 执行过程为： 1.找到AMENT_PREFIX_PATH目录 2.目录下的lib/功能包名/可执行文件名
export AMENT_PREFIX_PATH= 修改环境变量
～/.bashrc 默认脚本（以点开头的是隐藏文件 ls -a 显示隐藏文件）

2.1 ROS节点

进入所在文件夹 code ./ 用vscode打开所在文件夹
ros2 node list 查看节点列表
export RCUTILS_CONSOLE_OUTPUT_FORMAT=
[{function_name}:{line_number}]:{message}		 修改打印出来的

2.1.1功能包组织Python节点

1.ros2 pkg create ‘…..’(ros2 pkg create –help)
如 ：ros2 pkg create –build-type ament_python –license Apache-2.0 demo_python_pkg		 创建功能包
1.Setup.py中的entry_points，
‘python_node = demo_python_pkg.python_node:main’ (节点名 = 节点文件夹名.节点名：函数名)
1.1 python_node会生成inatall/lib下面的可执行文件名
2.colcon build 之后出现三个文件夹 原本pkg的文件会拷贝一份到install中的 python/site-packages下面
2.1运行时也是运行这install中的 python/site-packages下面的复制文件
1.输入命令 source install/setup.bash
2.查看环境变量 printenv | grep PYTHON
3.运行检查 ros2 run pkg文件名 node名		 自动修改更改环境变量（只对当前终端有效）

目录包的作用：

demo_python_pkg:与上层目录名保持一致，用于放置节点代码，开发主战场，init是标识文件，init出现说明该文件是python包

resource：放置资源，无需关系

test：测试文件

license：证书文件

package：功能包清单文件，依赖

setup.cfg:python包的配置选项

setup.py:入口声明

2.2 多功能包的最佳实践WorkSpace

工作包创建流程：

1.创建工作区 topic_ws/src

2.创建功能包 ros2 pkg create demo_python_topic –build-type ament_python –dependencies rclpy example_interfaces –license Apache-2.0

3.colcon build 构建

4.在setup.bash中console.script 配置main函数

5.source install/setup.bash

6.ros2 run 运行
